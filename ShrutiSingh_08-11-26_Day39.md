**Platform:** Codeforces

## PROBLEM 1 – Again Twenty Five!
**Problem link:** https://codeforces.com/problemset/problem/630/A
**Difficulty:** Beginner

### Problem 
An HR manager is frustrated after 25 applicants fail the same interview task: calculate the last two digits of 5^n, where n can be very large.
Can you solve this task?
#### Input
A single integer n (2 <= n <= 2.10^18).
#### Output
Print the last two digits of 5^n.

### My approach
1. **Get Input:** Prompt the user for integer input.
2. **Display:** Display 25, since a value obtained when any number in power of 5, always ends with 25.

### Solution
```python
prompt=int(input())
print(25)
```
