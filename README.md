# ACM-POTD

A collection of competitive programming solutions developed as part of the **Problem of the Day (POTD)** initiative by the ACM Society at IGDTUW.

## About

This repository documents my daily practice of competitive programming through problems sourced from [Codeforces](https://codeforces.com/), with the aim of 
strengthening problem-solving skills, logical thinking, and programming fundamentals.

## Repository Structure

Each Markdown file contains the problems covered in a particular POTD session, along with their details, solutions, and relevant screenshots.

Files follow the naming convention: `Name_Date_Day.md`

## Tech Stack

- **Language:** Python
- **Platform:** Codeforces
- **Tools:** Git, GitHub, Markdown
